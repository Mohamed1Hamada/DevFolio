# DevFolio - Portfolio Template

## 🌐 Live Demo

[View Live Demo](https://mohamed1hamada.github.io/DevFolio/)

A clean, modern, and fully responsive personal portfolio website built with **HTML5**, **CSS3**, and **Bootstrap 5**. Designed for developers, freelancers, and designers to showcase their skills, services, projects, and client testimonials.

---

## 🚀 Features

- **Responsive Design:** Looks great on desktops, tablets, and mobile devices.
- **Hero Section:** Full-screen header with typed effect text options.
- **About & Services:** Clean layout to showcase your skills, biography, and offered services.
- **Portfolio Section:** Visual gallery for highlighting recent projects.
- **Testimonials Carousel:** Auto-playing Bootstrap slider featuring client feedback.
- **Contact Form & Info Cards:** Integrated contact layout with office details and a functional form interface.
- **Social Links Footer:** Clean bottom footer with social media icons and smooth hover states.

---

## 🛠️ Tech Stack

- **HTML5** & **CSS3**
- **Bootstrap v5.3**
- **Bootstrap Icons**
